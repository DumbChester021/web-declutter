# FB Feed Cleaner

A lightweight browser extension that helps you take control of your Facebook feed by automatically hiding unwanted suggestions and tracking blocked content, providing a cleaner, distraction-free browsing experience.

## Features

- **Hide Suggestions**: Automatically removes "Suggested for you" and similar injected posts from your feed.
- **Track Statistics**: Keep track of how many posts have been hidden during your current session and over all time.
- **Whitelist Support**: Maintain a whitelist of things you want to keep visible.
- **Recent Block History**: View a list of recently blocked posts straight from the extension popup.
- **Data Management**: Clear your block history and reset your statistics at any time.

## Installation

### Load Unpacked (Chrome / Edge)
1. Clone this repository or download the source code:
   ```bash
   git clone https://github.com/YOUR_USERNAME/web-declutter.git
   ```
2. Open your browser and navigate to the extensions page (e.g., `chrome://extensions/`).
3. Enable **Developer mode** (usually a toggle in the top right corner).
4. Click **Load unpacked** and select the directory containing the extension files.

## Usage

Simply visit Facebook once the extension is installed. The extension works automatically in the background to monitor and filter your feed. 

Click the extension icon in your browser toolbar to:
- View real-time statistics of blocked posts.
- Review your recently blocked history.
- Clear your local data when needed.

## Permissions

- **Storage**: Required for saving your statistics, block history, and whitelist data locally.
